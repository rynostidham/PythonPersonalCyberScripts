### Password Generator ###
This is my first ever Python script created by me. The program creates a password that is customised by the user's input, and will display characters as well as digits and special characters if requested. The program uses a while true, try catch system to insure that user input is a valid positive integer. Through this project I learned how to use; int, import, while, try, catch, input, and for loops all inside of Python.
